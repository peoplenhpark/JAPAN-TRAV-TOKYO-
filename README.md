## 일정 요약

숙소가 **츠키지**라는 점을 축으로, **하루에 지하철 노선 하나씩만** 쓰도록 짰습니다.
요청지 7곳 전부 **환승 0회**입니다.

| 날짜 | 축 | 핵심 |
|------|-----|------|
| **9/5 (토)** | 오에도선 | 12:50 도착 → 츠키지 맛보기 → 하마리큐 → 긴자 보행자천국 → **도쿄타워 야경** |
| **9/6 (일)** | 히비야선 + 야마노테 | 에비스 가든플레이스 → 오사키 → **메구로강 강변 도보** → 나카메구로 → 시부야 야경 |
| **9/7 (월)** | 아사쿠사선 | **06:20 츠키지** → 센소지 → 스카이트리 → 소라마치 → **13:30 나리타行** |

### 이 일정이 이렇게 생긴 이유

- **츠키지가 Day 3 아침인 이유** — 장외시장은 **일요일 휴무**인데 9/6이 일요일입니다. 숙소에서 도보 5분이라 체크아웃 전에 다녀올 수 있고, 이른 아침이 원래 시장의 본모습입니다.
- **Day 3이 이른 시작인 이유** — 나리타 18:00 출발 → 15:00 공항 도착 → 이동 80분을 역산하면 **13:30 숙소 출발**이 고정됩니다.
- **한낮이 실내인 이유** — 9월 **상순**은 낮 30~32℃, 습도 70~75%입니다. 야외는 오전·저녁에, 13~16시는 실내로 배치했습니다.
